01 / LLM, RAG & Agentic AI

AI Rental Assistant with Retrieval-Augmented Generation

LLMRAGpgvectorBM25Tool callingPostgreSQL / SupabaseTypeScript
Code →RAG design →

A chat assistant for TuraKGL, a Kigali rental platform. It has two tools. One searches live listings in PostgreSQL, so every home it recommends is real. The other is retrieval-augmented generation (RAG) over the platform's help, terms and privacy text, so answers about payments, privacy or viewing rules come from the platform's own documents, with numbered citations.

Retrieval is hybrid: pgvector embeddings catch paraphrases, BM25 catches exact terms like "MoMo" or "PIN", and reciprocal rank fusion merges the two. Ingestion only re-embeds text that changed. If the vector store fails, the assistant falls back to keyword search instead of breaking. When nothing relevant is found, it says it doesn't know.

02 / Data Engineering

Weather Lakehouse: ETL Pipeline with Quality Gates

PythonDuckDBParquetPostgreSQLDockerGitHub Actions
Code →Architecture notes →

An end-to-end pipeline that pulls hourly weather data for Kigali, Nairobi, Lagos, Cape Town and Accra from a public API. Raw responses are kept for audit and replay, then the data moves through bronze, silver and gold layers into a dimensional model with daily marts and anomaly metrics.

A written data contract sets the rules for every column. Automated quality gates check row counts, uniqueness and valid ranges, and stop the run when data breaks them. Runs are idempotent, the code is tested in CI, and Docker adds PostgreSQL and S3-compatible storage for a fuller platform.

Pipeline layers
Public API→Raw JSON→Bronze Parquet→Silver tables→Gold marts→Quality gate
Checks: non-empty facts · unique city + timestamp · temperature, humidity and precipitation ranges
03 / Data Quality & Governance

Health Data Quality Audit and KPI Framework

PythonPandasData profilingMetric definitionsDashboard
Code →

A review of three months of telemedicine data across five linked tables: patients, consultations, lab tests, prescriptions and referrals. I profiled every table and join, then logged 19 quality checks, each with a severity, likely cause and what it means for reporting.

One check showed the data dictionary was wrong: it said 18% of referrals would fail to join, but none did. I documented the test instead of forcing the expected result. I then defined five governance metrics with explicit denominators and exclusions and built a one-page dashboard for a clinical governance committee.
