# Daniel Kwizera: portfolio site

Source for my portfolio page: a single, self-contained `index.html` with no build step.

It presents six projects with public code: an LLM assistant with retrieval-augmented generation, a governed ETL pipeline, a data quality audit, attention-based speech recognition, a reproducible ML pipeline and a PostgreSQL indicators warehouse.

To view it locally, open `index.html` in a browser. To publish it, enable GitHub Pages (Settings → Pages → deploy from the `main` branch).
